## PDF links via Google Drive

1. Open the website.
2. Press **M + P** on the keyboard to unlock the hidden edit panel.
3. Paste your Google Drive PDF link for each catalog.
4. Click **Save**.

Supported format example:

`https://drive.google.com/file/d/FILE_ID/view`

The website automatically converts Drive file links into preview mode in the popup viewer.

## Important note

Browser storage key was updated to `mp_v6` so the new thumbnails show correctly even if you opened an older version before.

## Deploy to GitHub Pages

1. Upload all files and folders to the root of your GitHub repository.
2. Go to **Settings > Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and `/root` folder.
5. Save.
