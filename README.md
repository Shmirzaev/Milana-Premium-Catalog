# Milana Premium Catalog Website

GitHub Pages ready.

## Thumbnail logic in this version

Each catalog now uses only **2 thumbnail images**:

- `*-en.png`
- `*-uz.png`

Language behavior:

- **ENG** -> English thumbnail
- **UZB** -> Uzbek thumbnail
- **RUS** -> English thumbnail fallback

The PDF / Google Drive link is shared across all languages.

## Upload to GitHub

Upload these to the repository root:

- `index.html`
- `covers/`
- `README.md`

## Update PDF links later

1. Open the website.
2. Press **M + P**.
3. Paste each Google Drive PDF link.
4. Click **Save**.
